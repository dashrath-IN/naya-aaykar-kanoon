Naya Aaykar Kanoon 2025

Income-tax Act, 1961 ↔ Income-tax Act, 2025 section mapper

Compiled by CA. Dashrath Maheshwari

About

The Income-tax Act, 2025 replaced the Income-tax Act, 1961 with effect from 1 April 2026, and almost every section number changed. Naya Aaykar Kanoon 2025 is a fast, offline reference tool that maps sections between the two Acts. It is built for Chartered Accountants, tax professionals, students, accountants and taxpayers.

Features
Feature	What it does
Two-way search	Type an old section (80C, 143(2), 44AB), a new section (123, 270) or a keyword
TDS / TCS finder	Maps old sections 192–206C to the serial numbers in the Tables of ss. 392, 393 and 394
Which Act?	Tells you which Act governs a date of payment, credit or accrual; converts Assessment Year ↔ Tax Year
Convert text	Paste a notice, letter or reply; every section reference is annotated with its 2025 Act equivalent
Browse	All sections of the 2025 Act grouped by subject
Descriptions and key changes	Short notes for frequently used sections, with recorded key changes where sources tie them to a section
CBDT-verified badge	Marks mappings confirmed against the CBDT comparison utility
Copy citation	One tap copies a professionally worded citation
Works offline	Install it as an app; no login, no ads, no data collection
